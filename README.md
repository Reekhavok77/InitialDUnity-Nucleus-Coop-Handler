# Initial D Arcade Stage 3 Reimagined — Nucleus Co-op Handler

A custom split-screen handler for **Nucleus Co-op** enabling local 2-player multiplayer for [*Initial D Arcade Stage 3 Reimagined*](https://github.com/distilledorion-sketch/Initial-D-Arcade-Stage-3-Reimagined)

## Requirements
* [Nucleus Co-op](https://nucleus-coop.github.io/) (Latest release recommended)
* A working copy of [**Initial D Arcade Stage 3 Reimagined**](https://github.com/distilledorion-sketch/Initial-D-Arcade-Stage-3-Reimagined)
* **2 Xinput controllers or just keyboard and controller

## Installation & Setup

1. **Download the Handler**
   * Download the `.js` handler file from [this](https://github.com/Reekhavok77/InitialDUnity-Nucleus-Coop-Handler/releases ) repository (or click **Code > Download ZIP** and extract it).
2. **Add to Nucleus Co-op**
   * Open **Nucleus Co-op**.
   * Drag the js file to Nucleus Coop ui (or extract the `.js` file directly into your `NucleusCoop/handlers/` folder).
   * Locate and select `InitialDUnity.exe` when prompted.
3. **Connect Your Controllers**
   * Plug in or connect both controllers via Bluetooth **before** launching the game.
   * Ensure both controllers show up as gamepad icons in the Nucleus Co-op player assignment screen.

## How to Play (Important!)

1. In Nucleus Co-op, select **Initial D Arcade Stage 3 Reimagined**.
2. Choose your preferred **split-screen layout** (e.g., Top/Bottom, Left/Right or another display) and drag one controller icon into each screen slot.
3. Click **Play** and wait for both game windows to launch, load, and resize automatically.
4. **Connect Multiplayer:** Use the in-game LAN / Multiplayer menu (Press F1) on both instances to join the same race lobby.
5. Have both Players ready and have the one who created the lobby start the race
6. have fun

## Troubleshooting

* **Only 1 controller works / Controller 2 controls Player 1:**
  * If using PlayStation or Switch controllers, make sure **DS4Windows** (or Steam Input) is running and emulating Xbox 360 (XInput) controllers before launching Nucleus Co-op.
* **Second window refuses to open:**
  * Check if an instance of `InitialDUnity.exe` is already running in Task Manager and close it before launching through Nucleus Co-op.
